# transport-empire# Transport Empire

A turn-based transport strategy game built in Java with JavaFX. Developed as a group project (team of 6) at ELTE over one semester.

## Features

- Build roads and bridges to connect cities
- Vehicles route automatically using A* pathfinding
- Economy engine - earn income from passengers, cargo, and buildings
- Bankruptcy detection and game over condition
- Save and load game state
- Main menu, settings, and new game UI

## Tech Stack

Java, JavaFX, JUnit, Maven, GitLab CI/CD

## How to Run

1. Make sure you have Java 17+ and Maven installed
2. Clone the repository
3. Run: `mvn javafx:run`
